# DIAMONDATA

구단 종합 비교와 선수·계약·FA 투자 분석을 위한 로컬 프런트엔드입니다. 별도 라이브러리 설치가 필요 없습니다.

## 실행

바로 확인하려면 `preview.html`을 더블클릭하세요. 서버가 필요 없는 단일 파일입니다.

개발할 때는 Node.js가 설치된 환경에서 이 폴더를 열고 `npm start`를 실행한 후 http://127.0.0.1:5173 으로 접속합니다. `index.html`을 직접 여는 대신 로컬 서버를 사용해야 외부 JavaScript 모듈이 동작합니다. 소스 수정 후 `node build-preview.mjs`를 실행하면 단일 파일 미리보기를 갱신합니다.

## 현재 기능

- 연도·리그·지구·구단·포지션 필터, 검색, 열별 정렬, 표시 열 선택, 행 간격 변경, CSV 다운로드
- 여러 구단을 선택하여 나란히 비교, 구단 상세의 선수 계약 탐색, 선수 상세의 시즌별 성적
- 구단 총연봉·FA 비용·팀 성적, 선수 연봉·성적, FA 계약, 계약 만료 예정, 가상 지출 한도
- 포지션/계약기간별 투자 결과, FA 계약 효율 순위, 선수별 시즌 추이
- 브라우저에 저장하는 관심 선수, 데이터 없음 상태와 계산 기준 안내

## 데이터 범위

8개 가상 구단, 구단당 8명, 2023/2024 두 시즌입니다. 실제 데이터가 아니며 MLB 리그명을 선택해도 실제 구단 성적·규정을 나타내지 않습니다. KBO는 데이터 없음 상태입니다. 가상 지출 기준액은 실제 CBT나 KBO 규정과 무관합니다.

FA 비용은 유효 FA 계약의 AAV 합계이며 시즌 실제 지급액과 다릅니다. 선수별 시즌 연봉 합계는 구단 총연봉과 일치합니다. 계약 만료는 FA 자격을 확정하지 않습니다.

## 파일

- `model.mjs`: 예시 데이터와 집계·순위 계산. 실제 API 연결 시 대체할 계층
- `app.mjs`: 화면 상태와 상호작용
- `styles.css`: 화면 스타일 및 반응형 레이아웃
- `server.mjs`: 로컬 미리보기 서버

`npm test`로 금액 합계·집계·순위 계산을 확인합니다. DB·PHP·로그인·실제 데이터 수집·계약 CRUD는 아직 구현하지 않았습니다. MariaDB의 기존 ERD에 시즌 연봉·FA 자격·지출 기준 데이터를 추가한 뒤 연결할 수 있습니다.
