# 프론트엔드 — DIAMONDATA

Modern v2 디자인을 실제 PHP/MariaDB 앱에 연결했습니다.

- 실제 실행 주소: `http://localhost/team07/`
- 구현 위치: `pages/`, `layout/`, `assets/`
- 기존 디자인 미리보기: `docs/frontend-preview/`
- [실행 방법·구현 내용·검증 결과·남은 확인 사항](FRONTEND_INTEGRATION.md)

흰색·그린 계열과 실제 사진 질감의 AI 생성 가상 경기장 이미지를 유지했습니다. 정적 미리보기 대신 기존 백엔드 쿼리를 사용하며, 분석값과 DB 쓰기는 팀 백엔드가 담당합니다.
